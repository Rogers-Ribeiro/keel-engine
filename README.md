# Keel — engine

Versão 0.2.0. **Gerado** a partir da base de conhecimento por `ferramentas/engine.mjs`; não se edita aqui.

## Instalar

```
/plugin marketplace add Rogers-Ribeiro/keel-engine
/plugin install keel@keel-engine
```

Depois, num projecto: `/keel-init` escreve o contrato no repositório, e `/keel-base` traz a base completa quando
for preciso confirmar a origem de uma regra.

## O que traz

- `agents/` — 2 ficheiro(s)
- `regras/` — 21 ficheiro(s)
- `docs/` — 11 ficheiro(s)
- `skills/` — 2 ficheiro(s)

## O que não traz

As transcrições dos cursos, as notas por secção e as sínteses por tema: milhares de ficheiros que tornariam a
instalação impossível. Vivem em https://github.com/Rogers-Ribeiro/keel e vêm com a skill `keel-base`.
